        Get the FreeMessenger app

        On other devices

        📱 Android
        Download the app (APK), or in Chrome: ⋮ → Install app.
        📱 iPhone and iPad
        In Safari (or Chrome, Edge, Firefox on iOS 16.4+): Share → Add to Home Screen. Open it from the home screen to get notifications.
        💻 Mac
        Safari: File → Add to Dock. Chrome or Edge: the install icon in the address bar.
        💻 Windows, Linux, ChromeOS
        Chrome or Edge: the install icon in the address bar, or ⋮ → Install FreeMessenger.
        🌐 Anything else
        Just open the site in any browser. Everything works there too.
